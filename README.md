# Agrotical - Project Μαθήματος Τεχνολογία Λογισμικού

Το παρόν repository αποτελεί μέρος της εξαμηνιαίας εργασίας του μαθήματος **Τεχνολογία Λογισμικού** (Τμήμα Μηχανικών Η/Υ και Πληροφορικής, Πανεπιστήμιο Πατρών).

## Τι είναι το έργο Agrotical

Το **Agrotical** είναι μια web εφαρμογή διαχείρισης αγροτικής παραγωγής με ρόλους χρηστών:
- **Farmer (Αγρότης):** παρακολούθηση χωραφιών, εργασιών, καιρού, οικονομικών και αναφορών.
- **Agronomist (Γεωπόνος):** παρακολούθηση χωραφιών αγροτών, φίλτρα υγείας/κατάστασης, βιβλιοθήκη καλλιεργειών.
- **Admin:** διαχείριση χρηστών.

Βασική ιδέα του έργου:
- συγκεντρωμένη εικόνα για καλλιέργειες και χωράφια,
- υποστήριξη λήψης αποφάσεων με δείκτες υγείας και συστάσεις,
- οικονομική αποτίμηση παραγωγής ανά χωράφι και ανά αγρότη.

## Τι περιέχει αυτό το repository

Προσοχή: το συγκεκριμένο repo είναι **καταγραφή προόδου/commits** και όχι πλήρες production-ready source tree.

- Το `src/app/data/mockData.ts` αναφέρεται στο commit που πρόσθεσε mock δεδομένα (χρήστες, χωράφια, εργασίες, συστάσεις, καιρικά, helpers, οικονομικούς υπολογισμούς).
- Υπάρχει πλήρης υλοποίηση για:
  - `src/app/pages/agronomist/AgronomistFields.tsx`
  - `src/app/pages/agronomist/AgronomistCropLibrary.tsx`

## Τι κάνει ο κώδικας (λειτουργικά)

Με βάση τα διαθέσιμα υλοποιημένα αρχεία και τη δομή του project:

- **AgronomistFields**
  - εμφανίζει χωράφια που αντιστοιχούν στον συνδεδεμένο γεωπόνο,
  - παρέχει αναζήτηση και φίλτρα (κατάσταση χωραφιού, επίπεδο υγείας),
  - εμφανίζει κρίσιμη ειδοποίηση για χαμηλή υγεία χωραφιών,
  - υπολογίζει/προβάλλει εκτιμώμενα οικονομικά ανά χωράφι.

- **AgronomistCropLibrary**
  - εμφανίζει λίστα καλλιεργειών από τα mock δεδομένα,
  - υποστηρίζει αναζήτηση και φιλτράρισμα ανά ανάγκες νερού,
  - προβάλλει αναλυτικά στοιχεία (απόδοση, κόστος, εποχικότητα, χρόνος ανάπτυξης),
  - δίνει γρήγορη εκτίμηση κέρδους ανά στρέμμα.

- **mockData (όπως περιγράφεται στα commits)**
  - ορίζει users, fields, tasks, recommendations, weather,
  - περιλαμβάνει helper συναρτήσεις αναζήτησης/συσχέτισης,
  - υπολογίζει οικονομικά μεγέθη για dashboards και αναφορές.

## Πώς τρέχει το πρόγραμμα

### Αν θέλετε runnable έκδοση
Για να τρέξει κανονικά το έργο, χρειάζεται το πλήρες αποθετήριο της εφαρμογής (με όλα τα αρχεία ρύθμισης). Τότε τα βήματα είναι:

1. Εγκατάσταση εξαρτήσεων:
   - `npm install`
2. Εκκίνηση σε development mode:
   - `npm run dev`
3. Άνοιγμα της διεύθυνσης που εμφανίζεται στο terminal (συνήθως `http://localhost:5173`).

## Σχέση με τις απαιτήσεις του μαθήματος

Το project ακολουθεί τη λογική του μαθήματος Τεχνολογία Λογισμικού:
- ανάπτυξη σε ομάδες και με χρήση Git,
- σταδιακή εξέλιξη με παραδοτέα και εκδόσεις,
- σύνδεση ανάλυσης/σχεδίασης με υλοποίηση κώδικα και testing.

Η καταγραφή ανά commit βοηθά να φαίνεται η πραγματική πρόοδος της ομάδας, όπως ζητά η εργασία.
